# 練習メニュー候補カタログの根拠

最終更新: 2026-09-03

このカタログは、生成時に外部サイトを検索する仕組みではない。公開資料を人が確認して候補種別として採用し、AIには保存済みかつユーザーが選択した候補だけを渡す。

## 採用した種別

- ランニング: イージー、リカバリー、フリー、控えめ／しっかりペース走、ウェーブ走。
- インドアバイク: 有酸素、リカバリー、テンポ、ケイデンス。
- 自重: 全身ベーシック、体幹ベーシック。

ペース走とウェーブ走は `moderate`、回復・フリー・ケイデンス・自重の基礎は `easy` とする。具体的なペースまたは心拍は、固定値ではなく保存済みのパフォーマンスプロファイルの範囲を利用する。痛み・疲労・週間負荷上限・時間・場所の制約は候補より優先する。

## 参照資料

- [England Athletics: Runner frequently asked questions](https://www.englandathletics.org/runtogether/support/runner-frequently-asked-questions/): テンポ走、ファルトレク、速い区間と定常走の組み合わせの種別。
- [England Athletics: Ask the coach](https://www.englandathletics.org/news/ask-the-coach-winter-motivation-track-v-gym-training-running-block-for-mixed-ability-runners/): リカバリーラン、ファルトレク、会話可能なロングスローランの位置づけ。
- [British Cycling: Indoor training sessions](https://www.britishcycling.org.uk/knowledge/training-plans/supporting-documents/article/izn20140529-Indoor-Training-Sessions-0): 室内トレーナー向けテンポ、ケイデンス、回復を含む種別。
- [World Athletics: treadmill training tips](https://worldathletics.org/news/performance/geoffrey-kamworor-treadmill-training-tips): テンポ、ファルトレク、スピード系を場所に応じて使い分けられること。

これらは候補分類の参考であり、個別のメニュー処方の転載ではない。医学的助言・故障診断・固定閾値として扱わない。
